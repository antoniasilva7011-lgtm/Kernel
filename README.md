# A52Q RisingOS 14 KernelSU

Build experimental para Samsung Galaxy A52 4G (`a52q`) baseada no mesmo kernel source apontado pela RisingOS 5.2 Android 14.

Base: `RisenID/kernel_samsung_sm7125`, branch `rising-14`.

O workflow integra KernelSU v0.9.5 para kernel non-GKI 4.14, habilita KPROBES e gera o kernel + pacote AnyKernel3 para TWRP.

> Experimental: sempre mantenha backup da partição Boot antes de testar.
